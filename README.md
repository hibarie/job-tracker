# 転職活動トラッカー

応募先の選考状況を一元管理できる、シンプルなWebアプリです。
自身の転職活動で「どの会社がどこまで進んでいるか」を把握しやすくするために個人開発しました。

## 主な機能

- 応募先の登録（会社名・職種・応募日・ステータス・条件メモ・求人URL・次にやること）
- 選考ステータスの変更（応募済み／書類選考中／面接調整中／面接済み・結果待ち／内定／不採用／辞退）
- 応募総数・選考中・内定の件数を集計して表示
- カードごとのメモ編集、削除
- 応募日の新しい順に並べて表示
- ダークモード対応、スマートフォン表示対応

## 使用技術

- HTML / CSS / JavaScript（フレームワーク不使用）
- データ保存：ブラウザの localStorage
- 開発支援：Claude Code などのAIコーディングツール

## 動かし方

ビルドやサーバーは不要です。`index.html` をブラウザで開くと動きます。
初回はサンプルデータが表示されます。画面右上の「サンプルデータに戻す」でいつでも初期状態に戻せます。

> 掲載しているデータはすべて架空のサンプルです。実際の応募データは含まれていません。

## ファイル構成

```
index.html  画面の構造
style.css   デザイン（ライト／ダークモード）
app.js      データの保存・集計・表示の処理
```
